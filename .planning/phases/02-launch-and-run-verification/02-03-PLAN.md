<objective>
Prepare the RUN-02 fixture so that its expected result is fixed before the GUI edit. Then run a read-only BUILD-05 preflight over the call sites. The preflight confirms that each site is tracked and built, records which RUN test reaches it, and records the baseline hashes of the compat.h lines that a migration must not disturb.

Purpose: RUN-02's pass rule needs one expected hash, computed from exact bytes before the test, so that a failure cannot be argued after the fact. BUILD-05's decisions for the sites that no test reaches are made on evidence, and the preflight provides that evidence.
Output: the RUN-02 fixture and its hashes, the BUILD-05 site table, and the compat.h baselines.
</objective>

  <files>~/runtests/runtest-utf8.txt, ~/runtests/runtest-utf8.initial.sha256, ~/runtests/runtest-utf8.expected.sha256, ~/runtests/expected/runtest-utf8.expected.txt, ~/runtests/logs/RUN-02.pre.txt (all outside the repository)</files>
  <action>Build the fixture with printf, so that every byte is known. Use only ASCII.
1. Write ~/runtests/runtest-utf8.txt with printf '%s\n' 'runtest line one'. The file then holds exactly the bytes "runtest line one" followed by one newline.
2. Write ~/runtests/expected/runtest-utf8.expected.txt with printf '%s\n' 'runtest line one' 'runtest line two'. The file then holds two lines, each ending in a newline.
3. Compute the initial hash of ~/runtests/runtest-utf8.txt with shasum -a 256, and write "<hash>  runtest-utf8.txt" (two spaces, relative name) to ~/runtests/runtest-utf8.initial.sha256. Run this from ~/runtests so the name is relative.
4. Compute the expected hash of ~/runtests/expected/runtest-utf8.expected.txt, and write "<hash>  runtest-utf8.txt" to ~/runtests/runtest-utf8.expected.sha256. The name is runtest-utf8.txt on purpose: after the GUI save, shasum -c checks the saved test file against the expected hash.
5. Check that the fixture is ASCII-only. Count the bytes outside printable ASCII and newline with LC_ALL=C tr -d ' -~\n' < ~/runtests/runtest-utf8.txt | wc -c. The count must be 0.
6. Write ~/runtests/logs/RUN-02.pre.txt with the time, the initial hash, the expected hash, and the line "pre-test record, before GUI edit". This is the record of the expected text, made before the test.
7. Do not open the file in TextMate or any other editor. Brian opens it in plan 04.</action>

    <automated>cd "$HOME/runtests" && shasum -a 256 -c runtest-utf8.initial.sha256 && test "$(cut -d ' ' -f1 runtest-utf8.initial.sha256)" != "$(cut -d ' ' -f1 runtest-utf8.expected.sha256)" && test "$(LC_ALL=C tr -d ' -~\n' < runtest-utf8.txt | wc -c | tr -d ' ')" -eq 0</automated>
    <fails_when>shasum prints FAILED (the initial file does not match its recorded hash). The initial and expected hashes are equal, so the test could not fail. The non-ASCII byte count is not 0.</fails_when>
  </verify>
  <done>runtest-utf8.txt holds the one-line initial content. Its hash matches runtest-utf8.initial.sha256. runtest-utf8.expected.sha256 names runtest-utf8.txt and holds a different hash. RUN-02.pre.txt records both hashes before the GUI edit.</done>

## Flagged assumptions and edge-probe dispositions (this plan)

- **Edge probe, RUN-02 "encoding".** Asks whose definition of equality applies: bytes, code points, graphemes, or normalized form. Disposition: resolved by the requirement's own test. Equality is the sha256 of the saved file's bytes (shasum -a 256). The fixture is ASCII-only, so no normalization or encoding question arises.
- **Edge probe, RUN-02 "empty".** Asks about empty, single-element, or null input. Disposition: out of the RUN-02 pass rule. The rule covers a known line that is edited and saved, not an empty file. Not tested by design. Flagged as A-06.
- **Edge probe, RUN-02 "concurrency".** Asks what is guaranteed if interrupted or run in parallel. Disposition: out of the RUN-02 pass rule, which names no interruption or parallel case. Not tested. Flagged as A-07.
- **Edge probe, BUILD-05 "adjacency".** Gestalt (lines 8 to 16) and AuthorizationExecuteWithPrivileges (lines 18 to 21) sit inside one deprecation-suppression block (lines 6 to 22). Disposition: a migration of Gestalt must leave lines 18 to 21 byte-identical. The baseline hashes above prove it.
- **A-06 (assumption).** An empty file is not part of RUN-02. Brian accepts this when he reviews the run log.
- **A-07 (assumption).** Interruption and parallel edits are not part of RUN-02. Brian accepts this.
- **A-18 (assumption).** Whether the initial load of the HTML output reaches the WebView policy delegate is not confirmed from source. It is recorded as not exercised. Site a stays an open item for Brian, since A1 does not cover it.
- **A-08 (assumption).** The expected saved content ends with a newline. TextMate does not add or strip a final newline on save with default settings. If it does, RUN-02 fails and the mismatch is recorded as the test result, not adjusted by hand.
</flagged_assumptions>
