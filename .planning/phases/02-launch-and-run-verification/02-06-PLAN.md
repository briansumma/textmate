| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-15 | Tampering | a migrated call site changes behavior | high | mitigate | One site per failure. The failing test is rerun, and every test that reaches the site is rerun. A retest failure stops the plan. The migration keeps the branch and result. |
| T-02-16 | Information disclosure | a push or a remote fetch | high | mitigate | No remote is added or used. The fetch uses the local path of this repository. No push is run. |
| T-02-17 | Repudiation | a commit that changes more than one ID | medium | mitigate | One commit per requirement ID. The message names the ID. The feature-freeze diff is checked against commit messages. |
| T-02-SC | Tampering | npm, pip, or cargo installs | high | mitigate | No install is run. The rebuild uses the Phase 1 ninja command only. |
