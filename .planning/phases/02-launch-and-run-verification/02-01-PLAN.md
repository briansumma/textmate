  <action>Set up the harness and run RUN-01 end to end. Use bash 3.2 features only, printf for output, and no Python. The executor runs this type="tracer" task as type="auto" (execute-plan.md line 233). The launch in step 5 is the only launch in this plan.
1. Create these directories with mkdir -p under ~/runtests: bin, logs, snapshots, lists, work, expected. Remove nothing.
2. Resolve the built app with find "$HOME/build/textmate" -name TextMate.app -print -quit. The expected output is /Users/bfs/build/textmate/release/Applications/TextMate/TextMate.app. If the output is empty, stop and report that Phase 1 output is missing. Do not build anything.
3. Write ~/runtests/bin/snapshot.sh. Its argument is a label. It writes ~/runtests/snapshots/LABEL.bundles.txt with one line per entry in "$HOME/Library/Application Support/TextMate/Bundles" and in "$HOME/Library/Application Support/TextMate/Managed/Bundles". Each line holds the folder name and its modification time from stat -f '%m'. Sort the lines with LC_ALL=C sort. The script also runs defaults export com.macromates.TextMate to ~/runtests/snapshots/LABEL.defaults.plist. Run it with label pre-run01 before step 5.
4. Write ~/runtests/bin/launch-check.sh. Arguments: the app path, then the mode run01, relaunch, or check. Steps for run01 and relaunch, in order:
   (a) If pgrep -x TextMate prints anything, exit 2. Print each PID with its ps -o command= line. Do not launch.
   (b) Run touch on ~/runtests/MODE.marker, where MODE is run01 or relaunch.
   (c) Run open on the app path.
   (d) Wait with perl -e 'select(undef, undef, undef, 30)' in run01 mode, or 10 seconds in relaunch mode. Do not use a bare sleep.
   (e) For each PID from pgrep -x TextMate, read ps -o command= -p PID. This step passes only when at least one command starts with the app path followed by /Contents/MacOS/TextMate. Otherwise exit 1 and print NOT THE BUILT APP and the command lines.
   (f) If ~/Library/Logs/DiagnosticReports exists, run find there with -newer ~/runtests/MODE.marker -name 'TextMate*'. Any output means exit 1, printed as NEW REPORT with each name. A missing folder counts as no reports.
   (g) Exit 0 only when (e) and (f) both pass.
   Mode check is read-only. It skips steps (a) to (d), writes no file, and runs steps (e) and (f) against ~/runtests/run01.marker. When no TextMate process runs, it exits 1 and prints NO TEXTMATE RUNNING. It never launches, touches, or kills.
   Write the full transcript to ~/runtests/logs/RUN-01-launch.log in run01 mode, or to RUN-05-relaunch.log in relaunch mode. Print the exit status, then the first 20 and last 20 lines of the transcript. The script never runs kill.
   Shell rules: set -u, quote every expansion, and keep shellcheck --exclude=SC1090 clean (shellcheck is at /opt/homebrew/bin/shellcheck). shfmt and yapf are aliases, not installed tools. Do not install anything.
5. Run the one launch: launch-check.sh with the app path and mode run01. This is the only launch in this plan. Record its exit status. The app keeps running after the script exits.
6. Write ~/runtests/logs/RUN-01.row as one tab-separated line: RUN-01, provisional status, exit status, log path, note. The provisional status is PENDING-WINDOW for exit 0, FAIL for exit 1, and OPEN for exit 2, since the precondition was unmet and the run did not happen. PENDING-WINDOW becomes PASS only at the checkpoint, after Brian confirms the window.
Do not edit any file in the repository.</action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| launch-check.sh to the process table | pgrep and ps report every TextMate process for this user, including the installed copy |
| built app to user state | The built app and the installed copy share ~/Library/Application Support/TextMate and the defaults domain |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Spoofing | open on the built app; process check | high | mitigate | Refuse to launch while any TextMate runs (exit 2). After launch, require a PID whose command path is the built app path (exit 1 otherwise). |
| T-02-02 | Tampering | bundle update poll during launch | high | mitigate | Take pre-run01.bundles.txt before launch. Plan 05 diffs it after RUN-03. A diff sets RUN-03 to OPEN and is recorded in the run log. |
| T-02-03 | Information disclosure | defaults snapshot | low | accept | The snapshot stays in ~/runtests, outside the repository. It is never committed. |
| T-02-SC | Tampering | npm, pip, or cargo installs | high | mitigate | This phase installs nothing. A missing interpreter is recorded as ENV-FAIL. No install is attempted. |
</threat_model>
