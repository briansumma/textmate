## Directory Purposes

- Purpose: All reusable libraries. Each subdirectory is one framework target, linked into `TextMate.app` and sometimes into helper apps.
- Contains: `default.rave`, `src/`, `tests/`, and optionally `resources/`, `gfx/`, `templates/`.
- Key files: `Frameworks/text/src/format.h`, `Frameworks/buffer/src/buffer.h`, `Frameworks/editor/src/editor.h`, `Frameworks/OakTextView/src/OakTextView.mm`, `Frameworks/document/src/OakDocument.h`.

**`Applications/`:**
- Purpose: Executable targets. Each has a `default.rave` that `require`s frameworks and defines its bundle or binary.
- Key files: `Applications/TextMate/src/main.mm` (GUI entry), `Applications/TextMate/src/AppController.mm`, `Applications/mate/src/mate.mm`, `Applications/PrivilegedTool/src/main.cc`, `Applications/SyntaxMate/src/main.mm`.
- `Applications/TextMate/` also holds `about/`, `icons/` (submodule, EMPTY here), `resources/`, `support/` (copied into `SharedSupport`), `templates/` (HTML header/footer), `Entitlements.plist`, `Info.plist`.

**`Applications/TextMate/src/`:** AppKit app code. Naming: `AppController <Topic>.mm` (for example `AppController Commands.mm`, `AppController Documents.mm`, `AppController Menus.mm`) are Objective-C categories on `AppController`.

**`PlugIns/`:**
- Purpose: Plug-in bundles copied into `TextMate.app/Contents/PlugIns` (`copy @Dialog @Dialog2 "PlugIns"` in `Applications/TextMate/default.rave`).
- Contains: `dialog/`, `dialog-1.x/` as submodules. Both are empty in this checkout. Until they are initialized (`git submodule update --init --recursive`), the `copy @Dialog @Dialog2 "PlugIns"` step in `Applications/TextMate/default.rave` has no contents to copy.

**`Shared/`:**
- Purpose: Headers and precompiled prelude shared by every target.
- `Shared/include/oak/` is on the include path for all C++ and ObjC++ (`-IShared/include` in root `default.rave`).
- `Shared/PCH/prelude.*` is force-included (`prelude Shared/PCH/prelude.*` in root `default.rave`).

**`vendor/`:**
- Purpose: Third-party code that is built in-tree.
- `vendor/Onigmo/`: regex engine sources. Its own `vendor/` submodule is EMPTY here.
- `vendor/kvdb/`: Objective-C wrapper around sqlite. Its `vendor/` submodule is EMPTY here.

**`bin/`:**
- Purpose: Build generator and dev scripts. `bin/rave` is the core: it parses `default.rave` files with `load` and `require` directives and writes `build.ninja`. Its `Compiler` subclasses (`CompileClang`, `CompileRagel`, `CompileCapnp`, `CompileXib`, `CompileAssetCatalog`, `ConvertToUTF16`, `ExpandVariables`, `CompileMarkdown`, `CreateBundlesArchive`) handle per-file transforms. Its `Target` module creates `objects`, `executable`, `lipo`, `assets`, `application`, `signature`, `runner`, `notarize`, `defines`, and `expand` steps.
- Tooling language: Ruby (shebangs point to the macOS system Ruby) and POSIX shell.

**`.github/workflows/`:** `build.yml` only. Runs on `macOS-latest`: `brew install ...`, `./configure`, `ninja TextMate`.

**Entry Points:**
- `Applications/TextMate/src/main.mm`: GUI process entry (`main`)

- `Frameworks/command/src/runner.mm`: bundle command execution
- `Frameworks/document/src/OakDocument.mm`: document model

## Naming Conventions

**Directories:**
- Frameworks: the directory name is the target name and the include prefix. Core frameworks use lowercase (`text`, `io`, `buffer`, `regexp`). UI and Cocoa-facing frameworks use `Oak` or CamelCase (`OakTextView`, `DocumentWindow`, `FileBrowser`). Keep these names: `#include <text/format.h>` depends on the directory name.
- Under each framework: `src/`, `tests/`, `resources/`, `gfx/`, `templates/`.

**C++ source files:**
- Core: `snake_case.cc` / `snake_case.h` (for example `Frameworks/text/src/case.cc`, `Frameworks/editor/src/snippets.h`).
- Objective-C++: `PascalCase.mm` / `PascalCase.h` (for example `Frameworks/OakTextView/src/GutterView.mm`, `Frameworks/FileBrowser/src/FileItemImage.mm`).
- Category and helper files may contain spaces: `NSColor Additions.mm`, `NSAlert Additions.h`, `OakDocument Private.h`, `AppController Commands.mm`. Use the same pattern when adding a category to an existing class (`Foo Bar.mm`) and quote the path in shell commands.

**Header guards:**
- Format: `<FILENAME>_H_<8 random uppercase alphanumerics>`. Examples: `COMMAND_RUNNER_H_MW7OSOTP` in `Frameworks/command/src/runner.h`, `COMPOSITE_H_BOKD8YWS` in `Frameworks/buffer/src/buffer.h`. Generate a new random suffix for each new header.

**Tests:**
- Unit: `tests/t_<unit>.cc` (for example `Frameworks/text/tests/t_ranker.cc`).
- GUI: `tests/gui_<unit>.mm` (for example `Frameworks/OakAppKit/tests/gui_dictionary.mm`).
- Test functions: `void test_<name> ()`, optional `void setup_<name> ()`, `void benchmark_<name> ()` (parsed by `bin/gen_test`).

**Namespaces (C++):**
- `ng` (editor core: `ng::buffer_t`, `ng::editor_t`, `ng::layout_t`, `ng::indexed_map_t`)
- `oak` (platform: `oak::basic_tree_t`, `oak::server_t`, `oak::application_t`)
- `text`, `path`, `plist`, `io`, `scope`, `command`, `ct`, `format_string`

**Objective-C classes:**
- `Oak*` for shared UI and model (`OakTextView`, `OakDocument`, `OakDocumentController`, `OakTabBarView`, `OakFilterList`)
- `OTV*` for text-view chrome (`OTVHUD`, `OTVStatusBar`)
- `TM*` for TextMate-wide types (`TMFileReference`, `TMPlugInController`)
- Process-wide services expose a `sharedInstance` class property (`@property (class, readonly) BundlesManager* sharedInstance`).

**Build and generated files:**
- Target definitions: `default.rave` in each target directory. Do not rename them.
- Generated and ignored: `local.rave`, `build.ninja`, `Frameworks/license/src/revoked_serials.cc` (listed in `.gitignore`).

**Assets:**
- `resources/` for PDF templates, `.xib`, `.storyboard`, `.icns`, `*.lproj` (for example `Frameworks/OakTextView/resources/Bookmark Template.pdf`, `Applications/NewApplication/resources/English.lproj`).
- `gfx/` for image assets used by a framework (`Frameworks/BundleEditor/gfx/`, `Frameworks/OakAppKit/gfx/`, `Frameworks/OakTabBarView/gfx/`).

## Where to Add New Code

**New editor action (for example, a new text command):**
- Enum value: add to `ng::action_t` in `Frameworks/editor/src/editor.h`
- Implementation: `Frameworks/editor/src/editor.cc` (or a new `Frameworks/editor/src/<topic>.cc` if it is large)
- Key binding: `Frameworks/OakTextView/src/OakTextView.mm` maps keys to actions
- Tests: `Frameworks/editor/tests/t_<topic>.cc`

**New text utility (pure C++, no AppKit):**
- Implementation: `Frameworks/text/src/<topic>.cc` with header `Frameworks/text/src/<topic>.h`
- Tests: `Frameworks/text/tests/t_<topic>.cc`

**New buffer or layout behavior:**
- Buffer: `Frameworks/buffer/src/` (`buffer.cc` for API, `storage.cc` for raw bytes, `parsing.cc` for scopes)
- Layout: `Frameworks/layout/src/layout.cc` (wrap/fold), `Frameworks/layout/src/render.cc` (drawing)
- Tests: `Frameworks/buffer/tests/` or `Frameworks/layout/tests/`

**New language/grammar feature:**
- Parse: `Frameworks/parse/src/`
- Scope matching: `Frameworks/scope/src/`
- Bundle item loading: `Frameworks/bundles/src/`

**New bundle command type or runner feature:**
- Parser: `Frameworks/command/src/parser.cc`
- Runner: `Frameworks/command/src/runner.mm`
- UI entry: `Frameworks/OakCommand/src/OakCommand.mm`

**New AppKit view or control (generic):**
- Implementation: `Frameworks/OakAppKit/src/<Name>.mm` and `.h`
- Use the `Oak` prefix. Keep the file pair together.

**New feature window or view (feature-specific):**
- Create a new framework directory, for example `Frameworks/MyFeature/`, with `default.rave`, `src/`, and `tests/`. Use the template in `Frameworks/text/default.rave` (headers, sources, tests) and add `require` lines for any frameworks it needs.
- Add the name to `TM_FRAMEWORKS` in `.tm_properties` so include paths resolve.
- Link it into the app by adding its name to the `require` line in `Applications/TextMate/default.rave`.
- Check the dependency graph in `ARCHITECTURE.md` for cycles before adding `require` edges.

**New app-level menu item or action:**
- Menu definition: `Applications/TextMate/src/AppController Menus.mm`
- Action handler: `Applications/TextMate/src/AppController Commands.mm`
- Document-related actions: `Applications/TextMate/src/AppController Documents.mm`

**New CLI tool:**
- Source: `Applications/<tool>/src/<tool>.cc`
- Target: `Applications/<tool>/default.rave` (copy from `Applications/indent/default.rave`)
- Follow `cli-design` rules for flags and exit codes if the tool is user-facing.

**New shared header (used by many frameworks):**
- Platform utility: `Shared/include/oak/<name>.h`
- Test helper: `Shared/include/test/<name>.h`

**Utilities:**
- Shared C++ helpers: `Frameworks/text/src/`, `Frameworks/io/src/`, `Shared/include/oak/`
- Shared ObjC helpers: `Frameworks/OakFoundation/src/` (Foundation), `Frameworks/OakAppKit/src/` (AppKit), `Frameworks/ns/src/` (C++ to Foundation bridging)
