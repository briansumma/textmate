# Technology Stack

**Analysis Date:** 2026-10-19

## Languages

**Primary:**
- C++ (`-std=c++2a`) - Core data structures, text buffer, layout, parsing, SCM, network, and most `Frameworks/*/src/*.cc`. Set in `default.rave` (`set CXX_FLAGS`).
- Objective-C++ (`.mm`, ~159 files) - All AppKit/Cocoa GUI code: `Applications/TextMate/src/*.mm`, `Frameworks/*/src/*.mm`. Compiled with `-fobjc-abi-version=3 -fobjc-arc` (`default.rave`, `OBJCXX_FLAGS`).
- C (`-std=c99`) - Vendored regex engine `vendor/Onigmo/src/*.c` and `Applications/TextMate/` helpers. Set in `default.rave` (`set C_FLAGS`).

**Secondary:**
- Ruby - Build tooling. `bin/rave` (the build-file generator, `#!/usr/bin/env ruby`), `bin/gen_build`, `bin/gen_test`, `bin/gen_html`, `bin/expand_variables`, `bin/extract_changes`, `bin/update_changes`, `bin/gen_credits.rb`, `bin/show_log`. Scripts that use `#!/System/Library/Frameworks/Ruby.framework/...` depend on the system Ruby shipped with macOS.
- Ragel - State machines: `Frameworks/plist/src/ascii.rl` (compiled by `ragel -o $out $flags $in` in `bin/rave`, line ~640).
- Cap'n Proto schemas - `Frameworks/plist/src/cache.capnp`, `Frameworks/encoding/src/frequencies.capnp`. Compiled by `capnp compile` via the `.capnp` transform in `bin/rave` (line ~649-660).
- Shell - `configure` (`#!/bin/sh`), `bin/notarize_await` (`#!/bin/sh`).
- Markdown - Help and release notes compiled to HTML via `multimarkdown` (`bin/rave` transform `.md => .html`, line ~721). Sources: `Applications/TextMate/about/Changes.md`, `Applications/TextMate/resources/TextMate Help/*.md`.
- JavaScript - `Applications/TextMate/resources/WKWebView.js`, `Applications/TextMate/about/js/contributions.js`.
- Property lists / XIB - `Applications/TextMate/Info.plist`, `Applications/TextMate/Entitlements.plist`, ~14 `.xib` files in `Frameworks/*/resources/`.

## Runtime

**Target platform:**
- macOS only. Minimum deployment target `APP_MIN_OS "10.12"` (`default.rave`), passed as `-mmacosx-version-min` and `LSMinimumSystemVersion` (`Applications/TextMate/Info.plist`).
- Architectures: host architecture by default (no `-arch` in `default.rave`); `local-orig.rave` shows an optional `arch "arm64" "x86_64"` split for release builds (`-target macos-${arch}`). Template only; copy to `local.rave` to use.
- Bundle identifier pattern: `com.macromates.${TARGET_NAME}` (`Applications/TextMate/Info.plist`).

**Build tool:**
- Ninja (generated `build.ninja`, gitignored). Generated by `./configure` which runs `bin/rave -crelease -tTextMate`.
- Build targets: `ninja TextMate`, `ninja TextMate/run`, `ninja -t clean` (see `README.md`).

**Package Manager:**
- None for the app itself. Dependencies are system/Homebrew/MacPorts packages plus git submodules.
- Lockfile: Not applicable. Submodule pins are recorded in the git index (`.gitmodules`).
- Submodule state: at the time of analysis, all submodules are **uninitialized** in this working copy (`git submodule status` shows `-` prefix for `bin/CxxTest`, `PlugIns/dialog`, `PlugIns/dialog-1.x`, `vendor/Onigmo/vendor`, `vendor/kvdb/vendor`, `Applications/TextMate/icons`, `Applications/SyntaxMate/resources/SyntaxMate.tmBundle`). Run `git submodule update --init --recursive` before `ninja`.

## Frameworks

**Core (GUI):**
- AppKit / Cocoa - Primary UI. Linked per target in `default.rave` files, e.g. `Applications/TextMate/default.rave` (`frameworks Cocoa`).
- Carbon - Legacy APIs in `Frameworks/OakAppKit/default.rave`, `Frameworks/OakFilterList/default.rave`, `Frameworks/io/default.rave`; `prelude-mac.h` imports `Carbon/Carbon.h`.
- AudioToolbox, Quartz - `Frameworks/OakAppKit/default.rave` (`frameworks Carbon Cocoa AudioToolbox Quartz`). `Shared/PCH/prelude.m` imports `Quartz/Quartz.h` for QuickLook.
- WebKit (legacy `WebView` API) - `Frameworks/HTMLOutput/default.rave`, `Frameworks/SoftwareUpdate/default.rave`. Used by `Frameworks/HTMLOutput/src/OakHTMLOutputView.mm` and `Frameworks/HTMLOutput/src/browser/HOWebViewDelegateHelper.mm` (`WebView`, `mainFrame`, `WebPolicyDecisionListener`). `Applications/TextMate/src/AboutWindowController.mm` uses `WKWebView` (with `Applications/TextMate/resources/WKWebView.js`).
- Security / ServiceManagement - `Shared/PCH/prelude-mac.h`, `Frameworks/io/default.rave`, `Frameworks/network/default.rave`.

**Testing:**
- CxxTest (git submodule `bin/CxxTest`, from `github.com/textmate/cxxtest`) - unit test harness. Generated runners via `bin/gen_test`.
- Test sources: `Frameworks/*/tests/t_*.cc` (C++), `Frameworks/*/tests/gui_*.mm` (GUI, Objective-C++). Declared with `tests` / `cxx_tests` in each `default.rave`.
- Test HTTP server helper: `Shared/include/test/web_server.h`.

**Build/Dev:**
- `bin/rave` - custom Ruby build-file generator (DSL in `default.rave` and per-target `*/default.rave`). Loads `local.rave` and `{Applications,Frameworks,PlugIns,vendor}/*/*.rave`.
- Ninja - build executor.
- `xcrun` toolchain - clang (`xcrun --sdk macosx clang`), `ibtool`, `actool`, `lipo`, `codesign`, `altool` (see `bin/rave` lines ~607-1246).
- Clang ThinLTO - release builds: `-flto=thin` (`default.rave` `config release`).
- AddressSanitizer - debug builds: `-fsanitize=address -fno-omit-frame-pointer` (`default.rave` `config debug`).
- Notarization - `bin/rave` uses `xcrun altool --notarize-app` and `bin/notarize_await`. `altool` is the legacy notary tool; see CONCERNS if migrating to `notarytool`.

## Configuration

**Build configuration:**
- `configure` (shell) - Verifies dependencies, writes `local.rave` (if absent) with `FLAGS` and `LN_FLAGS` pointing to `/usr/local/include` and `/usr/local/lib`, then calls `bin/rave`.
- `default.rave` (repo root) - Global flags, language standards, `-DREST_API="https://api.textmate.org"`, `APP_MIN_OS`, debug/release configs.
- `local.rave` (generated, gitignored; **not present** in this working tree) - Per-machine overrides. Template: `local-orig.rave` (tracked). It sets `CS_IDENTITY` from `APPLE_DEVELOPER_ID`, notarization credentials from `APPLE_NOTARIZE_USER` / `APPLE_NOTARIZE_PASS`, and `~/nix-profile` include/lib paths.
- Per-target `default.rave` files under `Applications/*`, `Frameworks/*`, `PlugIns/*`, `vendor/*` declare sources, headers, `require`, `libraries`, `frameworks`, and tests.

**Editor configuration:**
- `.tm_properties` (repo root) - TextMate project settings: build target (`TM_NINJA_TARGET = 'TextMate/run'`), `TM_CXX_FLAGS` including `Shared/include`, tab size 3, `TM_ISSUE_URL` for `github.com/textmate/textmate/issues`.
- `vendor/Onigmo/.tm_properties` - per-vendor editor settings.

**Runtime configuration (user-facing):**
- Global settings: `~/Library/Application Support/TextMate/Global.tmProperties` (`Applications/TextMate/src/AppController.mm`).
- Default settings: bundled `Default.tmProperties` resource.
- `NSUserDefaults` keys: `rmateServerDisabled`, `rmateServerListen`, `rmateServerPort` (`Frameworks/Preferences/src/Keys.mm`). Default rmate port `52698`.
- Environment overrides for SCM tools: `TM_GIT`, `TM_HG`, `TM_SVN` (`Frameworks/scm/tests/*.cc`, `scm::find_executable`).
- Build environment variables read by `bin/rave`: `builddir` (`bin/gen_build`), `APPLE_DEVELOPER_ID`, `APPLE_NOTARIZE_USER`, `APPLE_NOTARIZE_PASS`, `TEXTMATE_CHANGES`, `TEXTMATE_VERSION` (names only; values are not recorded in this repo).

**Compiler / warning flags (from `default.rave`):**
- `-funsigned-char`, `-Wall -Wwrite-strings -Wformat -Winit-self -Wmissing-include-dirs`, `-Wno-parentheses -Wno-sign-compare -Wno-switch -Wno-c99-designator`.
- Release: `-Os -DNDEBUG -flto=thin`, dead-strip linker flags.

**Code signing and entitlements:**
- `CS_IDENTITY "-"` (ad-hoc) by default in `default.rave`; overridden to `${APPLE_DEVELOPER_ID}` in `local-orig.rave`.
- Entitlements: `Applications/TextMate/Entitlements.plist` (apple-events, addressbook, `disable-library-validation`, `get-task-allow` toggled by config).
- Hardened runtime: `--options runtime` in `CS_FLAGS` (`default.rave`).

## Platform Requirements

**Development:**
- macOS (CI uses `macOS-latest`; Travis config pins `osx_image: xcode7.2`, legacy).
- Xcode command-line tools (`xcrun`, clang, ibtool, actool, codesign).
- Homebrew or MacPorts packages: `boost`, `capnp`, `google-sparsehash`, `multimarkdown`, `ninja`, `ragel`, plus `libressl` in `.travis.yml` only. `curl` and `sqlite3` are expected from the system SDK.
- Headers and libs expected under `/usr/local/include` and `/usr/local/lib` unless overridden in `local.rave` (`configure`).
- Git with submodules (`git clone --recursive`).

**Production / distribution:**
- Distributed as a signed, notarized `.app` bundle (`TextMate.app`) in a `.tbz` archive; see `Frameworks/network/src/tbz.cc` for extraction and `Frameworks/SoftwareUpdate/` for in-app update.
- Released via `https://api.textmate.org` (`REST_API`); see `INTEGRATIONS.md`.
- Supports macOS 10.12 and later (`APP_MIN_OS`).
- Auxiliary products built by the same tree: `mate` CLI (`Applications/mate`), `tm_query` (`Applications/tm_query`), `bl` (`Applications/bl`), `PrivilegedTool` (`Applications/PrivilegedTool`), `QuickLookGenerator`, `SyntaxMate` (`Applications/SyntaxMate`), `pretty_plist` (`Applications/pretty_plist`), `indent`, `gtm`, `NewApplication`.
